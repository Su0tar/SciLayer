# 可编辑化与清晰重绘

## 对照原图重建

1. 读取真实参考图，记录原图宽高。场景比例与原图一致。为文字、边框、连接线和复杂插画分别建立对象与稳定 ID。
2. 文字逐项核对；不清楚的标记 `[待核对]`。圆角矩形、圆、菱形和普通连线用原生对象。曲线用少量语义 M/L/C/Q/Z 路径节点，不能逐像素描边。
3. 复杂插画使用原图归一化 crop；crop 是原图坐标，画布坐标是摆放位置，二者不能混用。渐变和圆角用统一数据字段，读取 get_reconstruction_schema 获取当前语法。
4. 按分区逐块对照边框与图像位置，尤其是弧形扇区、偏斜框、遮挡处。不要以规则矩形替代明显的自由曲线边框。
5. 简单单色图标可调用 vectorize_icons 得到语义模板匹配提案；检查歧义与预览。它只有有限模板，不是通用矢量描摹。用户要求试验此功能即授权预览，明显匹配可在本次转换中应用；不确定的先让用户选。
6. 带 expected_revision 提交，检查布局并查看真实预览。先保存 JSON 再导出。PPTX 与 SVG 保留基础原生对象；复杂图片的内部细节不独立可编辑；PSD 的非文字图层使用栅格缓存。

## 用户选择高清化之后

- 先锁定原始文字、边框与箭头坐标。模糊标签不交给重绘猜测；文字仍由原生文本处理。
- 将需要清晰化的插画去除周围留白，脚本拼成规则图集，保留每个槽位的 ID、原始裁剪区域、目标位置和间距。用一次 imagegen 处理可合并的图集；不是强制一次，失败时按需要迭代。
- 提示只增强/重绘插画，保持各槽位物体、方向、数量和顺序，不增加文字或跨槽位内容。生成前先查看输入图。
- 检查输出尺寸、数量、位置和语义；按映射裁回，仅替换对应插画。若物体跨槽、缺失或漂移，修正后才应用，不机械盲切。
- 目前通用插画图集由 Codex 配合脚本准备；内置 prepare_icon_atlas/vectorize_icon_atlas 专用于独立图标，不声称支持所有插画。内容指纹冲突时重新读取画布，保留用户期间的移动和替图。
- 优先将文字、框线、箭头、颜色、圆角、线型修改留给原生对象。仅改变这些属性不需要调用 imagegen。

## 连接与本地服务

推荐通过仓库 `npm run install:codex` 安装 skill 并注册 scilayer stdio MCP；MCP 自动启动本机服务。open_editor 返回 canvas_url，支持 MCP Apps 的宿主可渲染资源，Codex 也可以用 open_in_codex 打开右侧 browser。网页普通模式的“交给 Codex”会复制指令，需要粘回对话；不能宣称普通浏览器能自动操控 Codex。

若 MCP 未加载，先告知连接状态，可从用户实际克隆目录运行 `npm run doctor` 检查。不要猜固定磁盘路径，不修改无关配置，不绕过付费服务。完整安装与手动启动见仓库 README。
