# 分层友好的科研绘图提示词

从用户的内容建立节点清单和关系清单；将已知信息直接带入，缺失的科学含义先询问。用途与比例可依上下文确定，不能默默改写用户的精确标签。

可调整的生成提示词骨架：

```text
用途：科研流程图/机制框图/结构图；面向[论文/汇报]。
主题：[研究对象与核心问题]。
节点与层级：[完整清单，每项一个简短名称]。
关系：[起点 → 终点；因果/时间顺序/关联/反馈；有无方向]。
文字（逐字保留）：[精确标签，注明中文/英文]。
构图：[布局方向、分区、比例]。

纯白背景 #FFFFFF，无纸张纹理、无环境背景。图由四类清晰可分离的元素组成：
1. 少量、克制、平面示意插画或图标，每个插画独立，边缘清楚；不要画成精细海报。
2. 独立线框与模块分区，线宽一致；边框可选圆角，避免与插画粘连。
3. 独立文字标签，清楚、高对比、不倾斜，与插画、连线留足间距。
4. 清楚的箭头，沿空白通道连接节点，不穿字、不压图；明确起终点。
统一对齐与间距，少量协调配色，保留安全边。仅表达给定科学关系。
除非用户要求，不添加图题、页眉、Logo、多余说明或装饰。
避免：图文融合、字嵌在复杂纹理中、无意义装饰、遮挡、额外结论或虚构数据。
```

插画只表达已有节点含义，例如数据、样本、仪器、细胞、流程操作；不为满足图标要求添加新科学节点。四类元素在视觉上分离，不声称 imagegen 输出自身具有独立图层。

对用户已有的完整提示词只作必要的结构化与分层约束校准。白色背景和模块化是默认风格，用户的明确选择优先。生成后检查错字、缺失标签和箭头语义；未知内容标记待核对，不能凭重绘臆造。
